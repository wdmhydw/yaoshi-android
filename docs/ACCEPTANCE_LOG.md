# 发行验收

## 0.7.0 功能基线

在玄戒 O3 的独立应用数据目录，从空模型目录点击下载。暂停时保留了 338,913,979 字节，恢复后得到 986,881,024 字节。Android 端再次计算的 SHA-256 与上游发布文件一致，应用显示“已启用”。随后 CPU 完成了内置 7.77 秒普通话样例，保存一条完整转写。

JDK 本地 HTTP 测试覆盖重定向、续传、服务器忽略 Range、分段响应、中断、非法范围、大小不符、摘要错误及完整暂存文件恢复。失败路径检查旧模型保持可用。

390 CSS 像素宽的设备 WebView 上，记录卡片外侧各 22 px，内侧各约 17.55 px，操作按钮 48 × 48 px。真机触摸左滑可显示删除，菜单可打开。窄屏截图使用模拟记录标题。[测试截图](images/record-history.png)

另在 360、1100 CSS 像素宽的同一 WebView 上测得，卡片的左右内边距分别为 16.2、28.6 px，左右外边距为 22、40 px。三种视口均无水平溢出，卡片纵向相隔 10 px。

公开研究目录的合成 tile 也已在 O3 原驱动复测。DDR 和 L2B 各三轮均为 2,048/2,048 逐位一致，跳过启动时 2,048 个哨兵全部保留。

从同一源码构建的独立测试包与发布包逐项比对，DEX、全部 assets 和六个原生库字节一致。原开发证书到发布证书的轮换已在独立测试包上覆盖升级验证，原有模型和记录仍可读取。升级后 CPU 再次完成内置示例。

JDK 回归通过模型下载、完整本地导入、AI 请求与纪要正文、Word 导出、声纹身份、实时预览和 PCM 持久化检查。前端预览、回听时间轴、转写检索和光球生命周期测试通过。

同一台 O3 上，干净构建的 CPU 和 Vulkan 均完成同一段公开样例并保存完整记录。此短样例用于功能冒烟，不能代表长录音性能。

对齐两份转写后，CPU 和 Vulkan 首句文字与标点一致。Vulkan 将录音尾声的“嗯”另列为第二句，CPU 没有单列。0.7.0 的默认后端是 CPU。
